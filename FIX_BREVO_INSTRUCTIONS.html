🔧 Fix Brevo SMTP - Whitelist Your IP Address

⚠️ Current Issue: Your IP address is not authorized to send emails through Brevo SMTP.

Follow These Steps:

Step 1: Login to Brevo

Open: https://app.brevo.com/

Login with your credentials

Step 2: Navigate to SMTP Settings

1. Click on your profile icon (top right corner)

2. Select "SMTP & API"

3. Click on the "SMTP" tab

Step 3: Add Authorized IP

1. Scroll down to find "Authorized IPs" section

2. Click "Add an IP" button

3. Add one of these options:

  • For Development: Enter 0.0.0.0/0 (allows all IPs)
  • For Production: Enter your specific IP address

4. Click "Save"

Step 4: Test the Email

After whitelisting, test by submitting the contact form on your website

Or run this command in terminal:

node test-smtp.js
✅ After completing these steps:
Your contact form will send emails successfully to info@arkanarabialogistics.com

Alternative: Use Brevo API Instead

If you prefer to use the Brevo API (which doesn't require IP whitelisting):

  1. In Brevo dashboard, go to: SMTP & API → API Keys
  2. Click "Generate a new API key"
  3. Copy the key (it will look like: xkeysib-abc123... and be much longer)
  4. Replace the BREVO_API_KEY value in backend/.env
  5. Restart the backend server
